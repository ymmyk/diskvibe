# Goal Runs

One folder per goal execution:

```text
docs/loop/runs/YYYY-MM-DD-goal-slug/
  goal.md
  plan.md
  progress.md
  evidence.md
  deployment.md
  qa-checklist.md
  open-questions.md
```

Create files as needed; evidence is required before marking a goal complete.
